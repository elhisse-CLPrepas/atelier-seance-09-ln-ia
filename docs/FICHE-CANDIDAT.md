# Fiche candidat — Séance 09

## Consigne
Choisissez un seul problème professionnel ou pédagogique. Avant d'utiliser l'IA, écrivez une phrase par rubrique : sujet, public, besoin, objectif, résultat attendu, première action. N’utilisez aucune donnée confidentielle.

## Parcours dans le site
1. Visionner les diapositives.
2. Comparer au moins deux cas fictifs.
3. Compléter les trois étapes de l’**Atelier** : contexte, production, relecture. Vous pouvez revenir aux étapes précédentes sans perdre les champs.
4. Copier le **Prompt de production** dans l'IA de votre choix si vous souhaitez obtenir un brouillon ; cette action se déroule hors du site.
5. Corriger personnellement les six rubriques.
6. Télécharger la note V1, le prompt utilisé et la preuve portfolio.
7. Ranger les fichiers dans le dossier candidat.

## Trame en six rubriques
Sujet — Public concerné — Problème ou besoin — Objectif du document — Résultat attendu — Première action.
