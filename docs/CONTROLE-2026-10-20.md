# Audit initial du dossier — 20 octobre 2026 (avant corrections)

**Ce document conserve les constats du premier audit.** Les huit anomalies ci-dessous ont été traitées lors de la révision demandée par le pilote : relecture annulée après modification, origine fictive conservée, navigation du logo et bouton S10 corrigés, focus restauré, données locales normalisées, installation harmonisée et polices Google supprimées. Le bilan actuel et les limites sont dans [QUALITE-ET-LIMITES.md](QUALITE-ET-LIMITES.md).

La révision comporte dix tests de comportement et de contenu, un build Vite et un aperçu autonome régénéré et contrôlé par simulation. La capture du navigateur Windows a expiré malgré une récupération de fenêtre ; le rendu visuel reste à confirmer. Aucun statut VALIDÉ ni déploiement n’est attribué.

Statut : analyse technique effectuée ; validation humaine et contrôle visuel en attente.

## Contrôles effectués

- `npm run check` : 4 tests réussis, syntaxe JavaScript contrôlée.
- Après installation des dépendances, `npm run check` et `npm run build` réussissent. Build réalisé avec Vite 6.4.4 ; dossier `dist/` produit et `package-lock.json` créé.
- `node scripts/test-render.mjs` : 11 rubriques rendues avec un DOM simulé. Ce contrôle ne remplace pas un navigateur.
- Archives : les 13 fichiers Markdown correspondent au manifeste SHA-256 fourni. L'archive ZIP initiale n'étant pas disponible, cette vérification porte uniquement sur le manifeste local.
- Structure : Vite et JavaScript natif, modèles des deux livrables présents, logo et signature du pilote présents.
- Calendrier actif conforme aux consignes : 23/10, 26/10, 30/10 et 02/11/2026 ; horaire à confirmer.

- Distinction explicite entre export, relecture déclarée et validation humaine.
- CSS responsive, styles de focus et préférence de réduction des animations présents ; efficacité visuelle non vérifiée.

## Anomalies et recommandations

1. **Relecture périmée après modification** : le gestionnaire `data-field` conserve `form.reviewed` après modification de la note. Réinitialiser la déclaration de relecture quand le contenu change.
2. **Origine fictive perdue dans l'atelier** : `load-demo` importe un cas fictif, mais `noteMd` ne conserve pas cette provenance dans la note exportée. Ajouter un marquage visible tant que le document provient de cette démonstration.
3. **Retour accueil par le logo** : le logo ne fait que changer le fragment `#accueil`. Aucun gestionnaire `hashchange` ne met la rubrique à jour. Relier ce lien à la navigation de l'application.
4. **Préparation S10** : le bouton dédié ouvre la rubrique Prompts sans sélectionner `s10` ; il affiche donc le dernier onglet actif, initialement Production V1.
5. **Navigation clavier à vérifier et améliorer** : de nombreuses interactions remplacent tout le DOM via `render()`. Le focus du contrôle activé peut être perdu, notamment dans la checklist, le quiz et les diapositives. Préserver ou rétablir un focus pertinent et vérifier au clavier et au lecteur d'écran.
6. **Stockage local non typé** : le JSON sauvegardé est fusionné sans contrôle des types. Une valeur non textuelle dans `name` ou une rubrique peut faire échouer `.trim()`. Normaliser les valeurs à la lecture.
7. **Documentation du déploiement divergente** : le README annonce `npm ci`, tandis que le workflow utilise `npm install`. Aucun verrou de dépendances n'était présent à l'ouverture du dossier. Harmoniser documentation, verrou et workflow avant publication.
8. **Ressource externe de présentation** : le CSS Vite charge Google Fonts. Aucun champ n'est inclus dans cette requête ; la version autonome supprime cet import. Des polices locales permettraient aussi au site Vite de fonctionner sans ce chargement tiers.
