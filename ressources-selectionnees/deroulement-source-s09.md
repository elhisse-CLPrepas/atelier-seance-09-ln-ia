# Déroulement séance 09 - Note de cadrage courte
## Version Markdown alignée avec l'affiche annonce

**Module :** 03 - Documents professionnels  
**Semaine :** 05  
**Séance :** 09  
**Durée indicative :** 90 à 120 minutes  
**Statut :** V1 - À RELIRE  

---

## Intention

Cette séance apprend au candidat à cadrer une idée avant de produire un document professionnel avec l'IA.

Message central :

```text
Le prompt maître ouvre la voie.
Le cadrage donne la direction.
Le livrable prouve la progression.
```

---

## Résumé du déroulement

| Temps | Étape | Objectif |
|---:|---|---|
| 10 min | Ouverture | Passer du prompt au document professionnel |
| 15 min | Exemple | Lire une note courte et reconnaître ses parties |
| 20 min | Cadrage | Choisir son sujet et clarifier le besoin |
| 25 min | Production IA | Utiliser le prompt maître |
| 20 min | Correction | Simplifier, préciser, valider humainement |
| 10 min | Classement | Enregistrer le livrable et garder la preuve |

---

## 1. Ouverture - 10 min

Objectif :

```text
Installer l'esprit de production.
```

Exemple concret :

```text
Je veux présenter mon activité.
```

devient :

```text
Je prépare une note de cadrage pour une fiche de présentation.
```

Action candidat :

```text
Écrire son idée de départ en une seule phrase.
```

Résultat attendu :

```text
Une intention simple, compréhensible par le groupe.
```

---

## 2. Exemple - 15 min

Objectif :

```text
Observer la structure d'une note de cadrage courte.
```

Exemple concret :

```text
Sujet : préparer une fiche pour une activité de soutien scolaire.
Public : parents d'élèves.
Besoin : comprendre rapidement l'offre.
```

Action candidat :

```text
Repérer les six parties :
sujet, public, besoin, objectif, résultat, première action.
```

Résultat attendu :

```text
Comprendre que cadrer, c'est choisir ce qui compte.
```

---

## 3. Cadrage personnel - 20 min

Objectif :

```text
Transformer une idée en informations exploitables.
```

Questions à compléter :

```text
De quoi s'agit-il ?
Pour qui ?
Pourquoi ce sujet compte-t-il ?
Quel résultat veut-on obtenir ?
Quelle est la première action concrète ?
```

Action candidat :

```text
Compléter les cinq questions avant d'utiliser l'IA.
```

Résultat attendu :

```text
Une matière claire à donner au prompt maître.
```

---

## 4. Production IA - 25 min

Objectif :

```text
Utiliser le prompt maître de production.
```

Action candidat :

```text
Copier le prompt maître.
Remplacer les zones "...".
Générer une première version.
```

Résultat attendu :

```text
Un brouillon IA structuré en six parties.
```

---

## 5. Correction humaine - 20 min

Objectif :

```text
Relire et reprendre la responsabilité du document.
```

Exemple concret :

```text
Phrase vague :
Je vais mieux expliquer mon activité.

Phrase corrigée :
Je vais lister les matières, les niveaux concernés et les informations de contact.
```

Action candidat :

```text
Utiliser le prompt de correction.
Contrôler manuellement la version proposée.
Supprimer les phrases inutiles.
```

Résultat attendu :

```text
Une note plus claire, plus courte et plus professionnelle.
```

---

## 6. Classement - 10 min

Objectif :

```text
Classer le livrable et garder la preuve.
```

Fichier attendu :

```text
03-documents/note-cadrage-courte.md
```

Preuve :

```text
preuve-09-note-cadrage
```

Action candidat :

```text
Enregistrer le fichier.
Vérifier le nom.
Noter la preuve dans le portfolio.
```
