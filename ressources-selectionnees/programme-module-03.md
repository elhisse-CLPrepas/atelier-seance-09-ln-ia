## 1. Intention du module

Le module 03 (semaines 05 et 06) transforme les prompts en documents professionnels.

Le candidat ne doit pas seulement obtenir une réponse de l'IA.

Il doit apprendre à produire un document utile, structuré, relu, corrigé, classé et réutilisable.

Message central :

```text
Un document professionnel n'est pas une réponse copiée.
C'est une production contrôlée.
```

Le module 03 (semaines 05 et 06) installe quatre réflexes :

1. cadrer le besoin avant d'écrire ;
2. transformer l'idée en structure ;
3. produire une première version ;
4. corriger et classer le document comme preuve.

---

## 2. Objectifs pédagogiques

À la fin du module 03 (semaines 05 et 06), le candidat doit être capable de :

1. produire une note de cadrage courte ;
2. transformer une idée en fiche projet ;
3. préparer le plan d'un guide pratique ;
4. produire une première version de guide ;
5. utiliser l'IA comme assistant de rédaction et de correction ;
6. distinguer brouillon, V1 et version corrigée ;
7. classer les documents dans le dossier candidat.

## 4. Principe de production documentaire LN-IA

Cycle de production :

```text
Idée
→ cadrage
→ prompt
→ brouillon IA
→ correction humaine
→ document V1
→ classement
→ preuve portfolio
```

## 5. Semaine 05 - Séance 09 - Note de cadrage courte

**Date :** vendredi 23 octobre 2026 — horaire à confirmer.

**Type :** cadrage, synthèse, première production documentaire  
**Durée indicative :** 90 à 120 minutes  
**Posture :** produire court, clair et exploitable

### 5.1 Objectif de la séance

Apprendre à cadrer une idée ou un besoin dans un document court.

Une note de cadrage doit répondre à cinq questions :

1. De quoi s'agit-il ?
2. Pour qui ?
3. Pourquoi ?
4. Quel résultat attendu ?
5. Quelle première action ?

### 5.2 Message d'ouverture

```text
Avant de produire beaucoup, il faut cadrer juste.
Une note courte peut éviter beaucoup de dispersion.
```

### 5.3 Modèle de note de cadrage

```text
# Note de cadrage courte

## Sujet
...

## Public concerné
...

## Problème ou besoin
...

## Objectif du document
...

## Résultat attendu
...

## Première action
...
```

### 5.4 Prompt de production

```text
Tu es assistant de production documentaire.

À partir des informations suivantes, aide-moi à rédiger une note de cadrage courte.

Sujet :
...

Public concerné :
...

Besoin ou problème :
...

Résultat attendu :
...

Contraintes :
- texte clair ;
- phrases courtes ;
- pas de promesse excessive ;
- structure en 6 parties.

Format attendu :
Markdown.
```

### 5.5 Production guidée

Chaque candidat produit une note de cadrage liée à son objectif personnel.

Livrable :

```text
03-documents/note-cadrage-courte.md
```

### 5.6 Travail après séance

Relire la note avec trois questions :

```text
[ ] le sujet est clair
[ ] le public est identifié
[ ] le résultat attendu est visible
```

## 6. Semaine 05 - Séance 10 - Fiche projet

**Date :** lundi 26 octobre 2026 — horaire à confirmer.

**Type :** structuration de projet  
**Durée indicative :** 90 à 120 minutes  
**Posture :** transformer une intention en projet simple

### 6.1 Objectif de la séance

Transformer une idée en fiche projet exploitable.

La fiche projet aide le candidat à passer de :

```text
Je veux faire quelque chose.
```

à :

```text
Je sais quoi produire, pour qui, pourquoi et comment commencer.
```

### 6.2 Structure recommandée

```text
# Fiche projet V1

## Nom du projet
...

## Objectif
...

## Public cible
...

## Problème traité
...

## Solution proposée
...

## Livrables attendus
...

## Outils utiles
...

## Étapes de production
...

## Critères de réussite
...

## Prochaine action
...
```

### 6.3 Prompt de production

```text
Tu es conseiller en structuration de projet.

Transforme mon idée en fiche projet V1.

Mon idée :
...

Public cible :
...

Objectif :
...

Contraintes :
- rester simple ;
- ne pas inventer de données ;
- proposer des étapes réalisables ;
- terminer par une prochaine action.

Format attendu :
fiche projet en Markdown.
```

### 6.4 Production guidée

Chaque candidat transforme sa note de cadrage en fiche projet.

Livrable :

```text
03-documents/fiche-projet-v1.md
```

### 6.5 Correction en atelier

Questions de contrôle :

```text
[ ] l'objectif est clair
[ ] le public cible est visible
[ ] les livrables sont concrets
[ ] les étapes sont réalistes
[ ] la prochaine action est faisable
```

## 7. Semaine 06 - Séance 11 - Plan de guide pratique

**Date :** vendredi 30 octobre 2026 — horaire à confirmer.

**Type :** planification documentaire  
**Durée indicative :** 90 à 120 minutes  
**Posture :** organiser avant de rédiger

### 7.1 Objectif de la séance

Créer le plan d'un guide pratique court.

Un guide pratique doit aider une personne à faire quelque chose.

Il doit donc être :

- clair ;
- ordonné ;
- concret ;
- utilisable ;
- adapté au public.

### 7.2 Modèle de plan

```text
# Plan de guide pratique

## Titre du guide
...

## Public visé
...

## Résultat promis
...

## Pré-requis
...

## Partie 1 - Comprendre
...

## Partie 2 - Préparer
...

## Partie 3 - Produire
...

## Partie 4 - Vérifier
...

## Partie 5 - Améliorer
...

## Checklist finale
...
```

### 7.3 Prompt de production

```text
Tu es rédacteur pédagogique.

À partir de ma fiche projet, propose le plan d'un guide pratique court.

Le guide doit aider le public suivant :
...

Objectif du guide :
...

Contraintes :
- maximum 5 parties ;
- langage simple ;
- orientation action ;
- inclure une checklist finale.

Format attendu :
plan détaillé en Markdown.
```

### 7.4 Production guidée

Chaque candidat produit le plan d'un guide lié à son projet.

Livrable :

```text
03-documents/plan-guide-pratique.md
```

### 7.5 Travail après séance

Choisir une seule partie du guide à rédiger en priorité.

Règle :

```text
Mieux vaut un guide court utilisable qu'un long document jamais terminé.
```

## 8. Semaine 06 - Séance 12 - Guide pratique V1

**Date :** lundi 2 novembre 2026 — horaire à confirmer.

**Type :** rédaction, correction, classement  
**Durée indicative :** 90 à 120 minutes  
**Posture :** produire une V1 exploitable

### 8.1 Objectif de la séance

Rédiger une première version de guide pratique.

Le guide V1 n'est pas final.

Il doit être assez clair pour être relu, corrigé et amélioré.

### 8.2 Message d'ouverture

```text
La V1 sert à exister.
La correction sert à progresser.
La preuve sert à valider.
```

### 8.3 Structure minimale du guide V1

```text
# Guide pratique V1

## Objectif du guide
...

## Pour qui ?
...

## Étape 1
...

## Étape 2
...

## Étape 3
...

## Erreurs à éviter
...

## Checklist finale
...

## Prochaine amélioration
...
```

### 8.4 Prompt de rédaction

```text
Tu es rédacteur pédagogique.

Rédige une première version de guide pratique à partir du plan suivant :
...

Public visé :
...

Contraintes :
- phrases courtes ;
- ton clair et professionnel ;
- étapes numérotées ;
- inclure les erreurs à éviter ;
- inclure une checklist finale ;
- terminer par les améliorations possibles.

Format attendu :
Markdown.
```

### 8.5 Correction du guide

Prompt de correction :

```text
Relis ce guide pratique.

Améliore-le selon ces critères :
- clarté ;
- ordre logique ;
- utilité pour le public ;
- phrases plus simples ;
- checklist plus actionnable.

Ne change pas l'objectif principal.
Signale les points à vérifier par l'humain.
```

Livrable :

```text
03-documents/guide-pratique-v1.md
```

### 8.6 Travail après séance

Préparer une version corrigée si nécessaire :

```text
03-documents/guide-pratique-v1-corrige.md
```
