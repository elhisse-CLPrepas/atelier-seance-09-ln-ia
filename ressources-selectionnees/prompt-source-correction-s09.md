# Prompt maître 02 - Correction humaine guidée

**Usage :** améliorer une note de cadrage déjà produite.

```text
Relis ma note de cadrage courte.

Améliore-la selon ces critères :
- sujet clair ;
- public identifiable ;
- besoin formulé simplement ;
- objectif concret ;
- résultat attendu visible ;
- première action faisable.

Contraintes :
- ne change pas mon intention principale ;
- garde une version courte ;
- utilise des phrases simples ;
- signale les points que je dois vérifier moi-même ;
- distingue clairement correction de contenu et correction de style.

Format attendu :
1. Version corrigée
2. Points à vérifier par l'humain
3. Checklist finale
4. Suggestion de classement dans le portfolio
```
