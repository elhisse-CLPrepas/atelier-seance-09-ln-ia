## 1. Intention de la séance

Cette séance ouvre le module 03.

Elle aide les candidats à passer d'une idée générale à un document court, clair et exploitable.

Message central :

```text
Avant de produire beaucoup, il faut cadrer juste.
Une note courte peut éviter beaucoup de dispersion.
```

La note de cadrage courte sert à fixer :

1. le sujet ;
2. le public concerné ;
3. le besoin ou problème ;
4. le résultat attendu ;
5. la première action.

---

## 2. Objectifs pédagogiques

À la fin de la séance, le candidat doit être capable de :

1. expliquer le rôle d'une note de cadrage ;
2. formuler un sujet en une phrase simple ;
3. identifier un public concerné ;
4. décrire un besoin sans dispersion ;
5. produire une note de cadrage courte en Markdown ;
6. relire son document avec une checklist simple ;
7. classer le livrable comme preuve de séance.

## 5. Mini-cours

Une note de cadrage n'est pas un long rapport.

Elle répond simplement à ces questions :

```text
De quoi parle-t-on ?
Pour qui ?
Pourquoi ce sujet compte-t-il ?
Quel résultat veut-on obtenir ?
Quelle est la première action concrète ?
```

Une bonne note de cadrage est :

- courte ;
- précise ;
- orientée action ;
- compréhensible par une autre personne ;
- utile pour préparer un document plus complet.

---

## 6. Exemple simple

```markdown
# Note de cadrage courte

## Sujet
Préparer une fiche de présentation pour mon activité de soutien scolaire.

## Public concerné
Parents d'élèves du collège et du lycée.

## Problème ou besoin
Les parents veulent comprendre rapidement ce que je propose, pour quels niveaux et avec quelle méthode.

## Objectif du document
Présenter mon offre de manière claire afin de faciliter un premier contact.

## Résultat attendu
Obtenir une fiche simple que je peux partager par WhatsApp ou imprimer.

## Première action
Lister les matières, les niveaux concernés et les informations de contact.
```

## 8. Prompt de production

```text
Tu es assistant de production documentaire.

À partir des informations suivantes, aide-moi à rédiger une note de cadrage courte.

Sujet :
...

Public concerné :
...

Besoin ou problème :
...

Résultat attendu :
...

Contraintes :
- texte clair ;
- phrases courtes ;
- pas de promesse excessive ;
- structure en 6 parties ;
- format Markdown ;
- ne pas inventer d'informations absentes.

Format attendu :

# Note de cadrage courte

## Sujet

## Public concerné

## Problème ou besoin

## Objectif du document

## Résultat attendu

## Première action
```

## 9. Prompt de correction

```text
Relis ma note de cadrage courte.

Améliore-la selon ces critères :
- sujet clair ;
- public identifiable ;
- besoin formulé simplement ;
- objectif concret ;
- résultat attendu visible ;
- première action faisable.

Contraintes :
- ne change pas mon intention principale ;
- garde une version courte ;
- utilise des phrases simples ;
- signale les points que je dois vérifier moi-même.

Format attendu :
1. version corrigée ;
2. points à vérifier par l'humain ;
3. checklist finale.
```

---

## 12. Erreurs fréquentes

À éviter :

1. écrire un texte trop long ;
2. mélanger plusieurs sujets dans la même note ;
3. oublier le public concerné ;
4. confondre objectif et résultat attendu ;
5. demander à l'IA d'inventer des détails ;
6. classer le fichier sans relecture humaine ;
7. appeler le fichier `document1.md` ou `final-final.md`.
