## Pourquoi cette fiche ?

Cette fiche aide à continuer le travail après la séance et à réviser le module 03.

La note de cadrage est une étape constructive du dossier professionnel. Elle prépare la fiche projet, le plan du guide et les documents professionnels suivants.

---

## Rappel important

```text
Un document professionnel n'est pas une réponse copiée.
C'est une production contrôlée.
```

Avant de demander à l'IA de produire, je dois clarifier mon besoin.

---

## Mon cadrage personnel

Compléter avant d'utiliser le prompt maître :

```text
Mon sujet est :

Le public concerné est :

Le besoin principal est :

Le document doit servir à :

Le résultat attendu est :

La première action possible est :
```

---

## Modèle de note de cadrage

```markdown
# Note de cadrage courte

## Sujet
...

## Public concerné
...

## Problème ou besoin
...

## Objectif du document
...

## Résultat attendu
...

## Première action
...
```

---

## Exemple concret

```markdown
# Note de cadrage courte

## Sujet
Préparer une fiche de présentation pour mon activité de soutien scolaire.

## Public concerné
Parents d'élèves du collège et du lycée.

## Problème ou besoin
Les parents veulent comprendre rapidement ce que je propose, pour quels niveaux et avec quelle méthode.

## Objectif du document
Présenter mon offre de manière claire afin de faciliter un premier contact.

## Résultat attendu
Obtenir une fiche simple que je peux partager par WhatsApp ou imprimer.

## Première action
Lister les matières, les niveaux concernés et les informations de contact.
```

## Travail à faire après séance

3. Vérifier que le public est clair.
4. Vérifier que le résultat attendu est concret.
5. Enregistrer le fichier avec le bon nom.
6. Ajouter la preuve dans le portfolio.
