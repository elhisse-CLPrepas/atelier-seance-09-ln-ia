# Prompt de correction guidée S09

Analyse ma note de cadrage courte selon ces six points : sujet précis, public identifiable, besoin clair, objectif utile, résultat observable, première action faisable.

1. Signale les ambiguïtés et informations inventées.
2. Propose une version corrigée sans modifier mon intention.
3. Présente les informations à vérifier par l'humain.
4. Conserve le format Markdown.
5. Ne prétends pas valider la note.
